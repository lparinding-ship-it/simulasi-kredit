APLIKASI SIMULASI KREDIT — RESPONSIF SEMUA PERANGKAT (2026)
Design & Development © 2026 Luther Parinding, S.Si.

YANG DIPERBARUI
• Otomatis menyesuaikan layar ponsel (iPhone/Android), tablet, dan komputer.
• Form dan dashboard menjadi satu kolom di ponsel, form dua kolom di tablet, dan sidebar di desktop.
• Ukuran huruf kolom input minimal 16px pada perangkat sentuh untuk menghindari zoom otomatis iPhone.
• Tombol cetak diperbesar; tersedia navigasi Input | Hasil | Angsuran di ponsel dan tablet.
• Tabel jadwal angsuran bisa digeser mendatar pada ponsel tanpa menggeser seluruh halaman.
• Area sentuh minimal sekitar 44px dan dukungan safe area perangkat iPhone.
• Tidak mengubah rumus maupun pengaturan kredit aplikasi versi sebelumnya.

PETUNJUK MENJALANKAN
Komputer Windows/macOS: ekstrak ZIP, kemudian buka Simulasi-Kredit.html dengan Chrome/Edge/Firefox/Safari.
Ponsel/tablet: untuk penggunaan Safari iPhone dan Android yang paling konsisten, letakkan file HTML ini di situs HTTPS internal atau web hosting tepercaya, kemudian buka URL-nya dari browser perangkat. Membuka berkas HTML langsung dari aplikasi Files/Quick Look iOS dapat membatasi JavaScript; hal itu tidak sama dengan membuka situs di Safari.
Aplikasi ini tidak membutuhkan library eksternal atau koneksi API untuk menghitung simulasi.

PENCETAKAN
• Ringkasan: A4, 1 halaman dalam pengujian Chromium (termasuk ukuran viewport ponsel).
• Jadwal angsuran: dapat dicetak seluruh tenor; contoh 84 bulan = 3 halaman A4.
• Aturan pemblokiran cetak karena batas usia dan IDIR tetap digunakan.
• Pengujian fisik Safari iOS tetap disarankan karena dialog cetak berbeda dari Chromium.
